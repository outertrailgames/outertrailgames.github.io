Outer Trail Games / Privacy

Website privacy

Last updated: October 27, 2026

This page covers the Outer Trail Games website. For the Android game, read the separate HexGlow Privacy Policy.

Visiting this website

This static website does not include analytics scripts, advertising, tracking pixels, cookies, browser storage, account registration, or contact forms. Its fonts and images are served with the site; there are no embedded third-party services.

GitHub Pages hosting

The site is designed to be hosted on GitHub Pages. GitHub states that it logs and stores visitors’ IP addresses for security purposes, including for visitors who are not signed in. See GitHub Pages data collection and the GitHub Privacy Statement for its handling and retention practices.

Email and external links

Email links open your email application. If you email the studio, your address and the information you choose to send are processed through email services so the studio can respond. Do not send unnecessary sensitive information. External links take you to services with their own privacy policies.

Retention and requests

This website does not store form submissions or accounts. GitHub manages its hosting logs. The studio’s retention period for support emails still needs to be confirmed; no fixed period is promised here. For questions about correspondence or a deletion request, email outertrailgames@gmail.com.

Changes and contact

Changes will appear here with an updated date. Outer Trail Games can be reached at outertrailgames@gmail.com for website or privacy questions.
